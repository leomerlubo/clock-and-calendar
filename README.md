# Clock & Calendar

A quiet, premium Android desk display designed for focused work.

## Features

* Adaptive portrait and landscape layouts
* Digital or analog clock
* Full month or today only calendar
* Curated palettes and custom HSV color picker
* Four curated minimalist typefaces with live previews
* Immersive full screen display with screen awake behavior
* Adjustable display brightness
* Optional seconds and 24 hour time
* Subtle pixel shifting for static screen protection
* Long press exit control to avoid accidental exits
* Offline, private, and free of notifications, accounts, ads, and analytics

## Build

Open the project in Android Studio and build the `app` module, or run `./gradlew assembleDebug` after generating a Gradle wrapper.
